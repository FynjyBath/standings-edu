Оценки задач

← В админку JSON-редактор

Сложность задачи оценивается по её условию и лежит в data/task_ratings.json. Эта оценка входит в цену задачи как предположение и вытесняется данными по мере того, как задачу решают: у задачи с сотней решивших она почти не видна, у новой — единственный источник. Здесь показаны только те задачи, где оценка спорит с наблюдаемым, — проверять остальные смысла нет.

Оценок пока нет

Заведите data/task_ratings.json — карту «нормализованная ссылка на задачу → оценка». Для каждой задачи два числа, оба в наблюдаемых величинах, чтобы их можно было сверить с фактом:

{
  "https://informatics.msk.ru/mod/statements/view.php?chapterid=2955": {
    "solve_rate": 0.65,
    "attempts": 1.5,
    "model": "claude-opus-5"
  }
}

solve_rate — какая доля дошедших до задачи учеников её возьмёт. attempts — сколько посылок уйдёт у типичного ученика до зачёта. Очередь появится здесь после ближайшей генерации.

«Принять факт» — оценка была неточной, записываем наблюдаемые числа и помечаем проверенной. «Оценка верна» — оценка правильная, а расходится с ней сама задача: стоит посмотреть, не разошлись ли решения, не слабы ли тесты и понятна ли формулировка. В обоих случаях оценка становится подтверждённой, и модель начинает доверять ей вдвое сильнее. В ценах задач это отразится после ближайшей генерации.
