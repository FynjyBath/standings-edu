Ссылки на задачи

Показывать ли ученикам ссылки на условия задач в таблицах. Если снять — на странице для учеников останутся только метки задач (A, B, C…), без переходов к условиям и посылкам. Жюри по токену ссылки видит всегда. Действует сразу, без перегенерации.

Записать список ФИО на группу

По одному ФИО в строке. Для ФИО, которых ещё нет в базе, создаётся пустая запись ученика (без аккаунтов) и он добавляется в группу; существующие — просто дописываются в группу. Сначала «Пробный запуск» покажет, что произойдёт (кто новый, кто уже есть, спорные совпадения). Аккаунты потом добавляются через анкеты/форму ученика.
